日志 003 · 交互细节 修改

让每一条记录都能被修改

网站写到现在，日志本身也需要被修改。以前只能整页重写，改一条记录要在一大段文字里来回找。今天在每条日志的标题旁边放了一个「修改」入口，点一下就直接回到这条记录在 GitHub 上的原文位置，改完提交即可。

学习札记的纵向空间也重新安排过。三张专题卡片比原来更高，留白更舒展；卡片本身还可以点击展开，展开后会看到该栏目收录的方向，以及为将来的笔记预先留出的位置。

这些改动都没有动整体的样子。颜色、圆角、留白和文字层级仍然是原来那一套，只在需要操作的地方多给了一点回应：鼠标移到卡片上时标题旁边会亮起来，展开时面板顺着高度滑出，收起时再安静地退回去。

  • 网站日志的每一条记录都增加了「修改」入口，可直达对应位置。
  • 学习札记的三张专题卡片改为可点击展开，并补充了各栏目的收录方向。
  • 加高札记卡片、放宽纵向留白，并补上一句页面说明。
  • 为展开与悬停补充了克制的动效，保持原有的安静节奏。

日志 002 · 设计整理 修改

让每一页说同一种语言

网站的内容逐渐多起来以后，今天重新整理了此前所有的设计决定。目标并不是让页面变得更热闹，而是让不同页面拥有同一种秩序：看起来安静，使用时清楚，阅读时不被多余的装饰打断。

整体继续使用黑、白、灰作为基础颜色，只把系统蓝留给分区标签、链接和交互反馈。圆角、细边框、柔和阴影和较大的留白共同构成页面的骨架。首页的人物信息与正文形成深浅对照，但不使用生硬的纯黑；人物面板只在首页出现，其他页面把空间留给内容。

顶部导航紧贴页面上方，Home、Publications、Study Notes 和 Site Log 均匀排列。语言控件也重新做成真正的双选分段按钮：当前语言保持选中，另一种语言可以独立点击，并准确进入当前页面的对应译文。

成果页面采用著作与期刊论文的左右分栏。著作使用较大的自然风景封面，期刊论文采用更紧凑的双列卡片。SSCI Q1、EI（JA）、CSSCI、CSSCI扩展和 AMI 等标注固定在卡片顶部；普通期刊不显示标签，但仍保留一致的版面节奏。

Study Notes 为研究方法、智能传播和全球传播设置了三张专题卡片，并保留上传文件与添加链接的入口。网站日志则使用时间轴记录正式文章，同时自动读取 GitHub 的最近提交，让细小的更新也有迹可循。

  • 统一首页及三个内容页的宽度、留白、圆角和文字层级。
  • 完善双语导航与可独立操作的语言分段控件。
  • 建立著作、论文、学习札记和网站日志的卡片系统。
  • 增加手动撰写日志与自动同步更新记录两种维护方式。
  • 补充桌面端、平板和手机端的响应式阅读体验。

日志 001 · 第一天 修改

建一间属于自己的小屋

今天，这个网站终于开始像一个真正的地方，而不再只是一份刚刚打开的模板。

最先放进去的是一些简单的东西：名字、照片、学校和研究兴趣。看起来都不复杂，做起来却很花时间。标题曾经出现两遍，照片一度被导航栏挡住，页面的末尾也跑到了屏幕之外。问题一个接一个地出现，我们便一个接一个地把它们改好。

后来，几个页面渐渐有了自己的秩序。首页安静下来，发表成果分成著作与期刊论文，学习札记也为研究方法、智能传播和全球传播留出了位置。中文和英文终于能够并排站在导航栏里，各自通往正确的页面。

到了晚上，网站当然还没有完成。不过这样也很好。它已经为今后的论文、笔记和许多尚未发生的变化留下了空间。今天只是把门打开，灯亮起来。

  • 建立中英文首页、导航和切换功能。
  • 完成个人信息面板、成果卡片与学习札记页面。
  • 补充期刊分区、自然风景封面和移动端适配。
